# Maestro Plan App

Klickbarer V0-Prototyp für die Personal-Training-App von Maestro Plan. Er zeigt sowohl die mobile Kundenerfahrung als auch Sergios Trainer-Dashboard mit simulierten Daten.

## Starten

Die Datei `index.html` direkt im Browser öffnen oder im Projektordner einen einfachen lokalen Webserver starten:

```powershell
npx.cmd serve .
```

Danach die angezeigte lokale Adresse im Browser öffnen. Auf dem Einstiegsbildschirm kann zwischen Kunden- und Trainer-Perspektive gewechselt werden.

## Enthaltene Demo-Abläufe

- Kunde: Heute-Ansicht, Wochenplan, geführtes Training, Timer, Ernährungs-Check-ins, Chat, Termine, Videothek und Fortschritt
- Trainer: Dashboard, Kundenliste, Kundenfortschritt, Plan-Builder, Zuweisung, Ernährung, Mediathek und Kundenvorschau
- Responsive Darstellung für Smartphone und Desktop

Der Prototyp verwendet ausschließlich Demo-Daten und hat noch kein produktives Backend.
